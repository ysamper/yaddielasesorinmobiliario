# GAN Design Evaluation Rubric

Pass threshold: **7.5** (weighted score)
Max iterations: **10**

## Design Quality (weight: 0.35)

Score 1-10 on:
- **Visual hierarchy**: Does the eye flow naturally? Is there clear primary/secondary/tertiary emphasis?
- **Typography**: Is the Cormorant Garamond + Outfit pairing used with sophistication? Letter-spacing, line-height, size scale?
- **Color**: Is the gold/off-white palette used with restraint and impact? Any creative extensions?
- **Spacing**: Is there generous, intentional whitespace? Does the layout breathe?
- **Composition**: Are sections visually distinct yet cohesive? Any asymmetry or tension?

## Originality (weight: 0.30)

Score 1-10 on:
- **Layout innovation**: Does it break from standard section-stacking? Overlapping elements, offset grids, editorial layouts?
- **Animation craft**: Are CSS animations purposeful and polished? Scroll-triggered reveals, micro-interactions?
- **Creative typography**: Any creative use of text — oversized numbers, mixed weights, editorial flourishes?
- **Memorable moments**: Would a designer screenshot this for inspiration? Any "wow" moments?
- **Category disruption**: Does it look different from other real estate sites?

## Craft (weight: 0.25)

Score 1-10 on:
- **CSS quality**: Clean, well-organized, using modern CSS (grid, custom properties, clamp)?
- **Responsive**: Does it work beautifully at all breakpoints, not just "not broken"?
- **Micro-details**: Border radii, shadows, transitions, hover states — all polished?
- **Consistency**: Do patterns repeat predictably? Is the design system coherent?
- **Performance**: No heavy assets, smooth animations, no layout shifts?

## Functionality (weight: 0.10)

Score 1-10 on:
- **Navigation**: Can users find investor vs seller paths easily?
- **CTAs**: Are call-to-action buttons prominent and clear?
- **Content readability**: Is the Spanish copy legible and well-formatted?
- **Links/forms**: Do all interactive elements work (RGPD checkbox, external links)?

## Scoring

```
weighted_score = (design_quality * 0.35) + (originality * 0.30) + (craft * 0.25) + (functionality * 0.10)
```

## Evaluator Notes

- A stunning half-finished redesign beats a functional but boring one.
- Push the Generator to take creative risks — unusual layouts, custom animations, distinctive color work.
- "Would this win a design award?" is the key question for Design Quality and Originality.
- Penalize safe, template-like designs even if technically correct.
- Reward creative leaps even if some sections are rough around the edges.
