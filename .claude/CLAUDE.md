# Yaddiel Samper — Asesor Inmobiliario Website

## Project

Astro v5 static site for a real estate investment advisor in Canary Islands.
Deployed on Netlify via GitHub. Content in Spanish.

## Stack

- **Framework:** Astro v5 with static output
- **Styling:** Vanilla CSS with design tokens in `src/styles/global.css`
- **Content:** Markdown blog posts in `src/content/blog/`
- **Deploy:** Netlify auto-deploy on push to `main`
- **Integrations:** Calendly, Lystos, Beehiiv, Google Analytics GA4

## Key Files

- `.agents/product-marketing.md` — Brand voice, ICP, positioning, market data
- `src/styles/global.css` — Full design system (colors, typography, components)
- `src/pages/index.astro` — Homepage
- `src/content/config.ts` — Blog post schema (Zod)

## Skills Available

- `/design-system` — Visual design tokens, component patterns, audit
- `/content-engine` — Blog posts, LinkedIn, newsletter following brand voice
- `/site-audit` — SEO, performance, RGPD, accessibility, conversion checks

## Rules

- All content in Spanish (es-ES)
- Brand voice: direct, short sentences (max 20 words), active voice, no em dashes
- Design: gold/cream palette, Cormorant Garamond headings, Outfit body, no dark mode
- RGPD: cookies blocked by default, consent before any tracking
- No paid dependencies — organic growth only
